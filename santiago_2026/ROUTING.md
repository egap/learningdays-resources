# Santiago 2026: how this site is put together

Live URL: https://egap.github.io/learningdays-resources/santiago_2026/

This folder is a **hub site** for the EGAP LatAm Learning Days (Universidad
Catolica de Chile, July 27-31, 2026), adapted from `../abidjan_2026/`. Unlike
abidjan, the lecture decks are NOT (yet) bilingual Quarto sources: the cards
on the landing page link to static PDFs (and one self-contained HTML) copied
from the workshop Dropbox. The folder keeps the full abidjan build machinery
so decks can be converted one at a time after the workshop.

Languages: Spanish primary, English secondary. Machinery uses `es`/`en`
codes everywhere (`lang-es` classes, `#es/...` hash routes, `SANTIAGO_LANG`
env var). Some copied filenames carry the legacy `_sp` suffix from Dropbox;
filenames were kept as the teaching team knows them (spaces removed only).

## Layout

- `index.qmd` -> `index.html` (committed): landing page. Two language panels
  (ES default), six tabs each: Diapositivas/Slides, Sesiones de R/R sessions,
  Lecturas/Readings, Recursos/Resources, Programa/Schedule,
  Instructores/Instructors. The deck grid, R-session list, and textbook links
  are generated by `scripts/index_helpers.R` from `index.csv`.
- `index.csv`: the registry driving the card grid. Schema:

  ```
  sort_order,label,href_es,href_en,title_es,blurb_es,title_en,blurb_en,placeholder
  ```

  Labels are day-session codes (`D1-1` .. `D5-1`) matching the Programa
  tables. A row may fill one or both href columns; the active panel uses its
  own language's href and falls back to the other language's file with a
  small EN/ES badge on the card. `placeholder,TRUE` renders a grey card with
  no link (sessions with no publishable deck).
- `slides/`, `r_sessions/`, `forms/`: static materials copied from Dropbox
  (see the file map below). Rmd sources are committed with their helpers
  (`rmd_setup.R`, `learningdays-book.bib`, `diagnosis1.rda`,
  `images/egap-logo.png`) so they stay knittable.
- `assets/`: santiago-bilingual.{lua,css,js} (deck filter + styles + language
  toolbar for future converted decks), santiago-index.css + index-tabs.js
  (landing page), flags, logo, bib.
- `0_make_everything.R`: build orchestrator. `--index-only` re-renders the
  landing page; `--html-only` / `--pdf-only` additionally render any deck
  whose `.qmd` source exists (today: none, they all skip cleanly).
- `scripts/convert_bilingual_rmd.py`, `scripts/fix_figures_qmd.py`: the
  conversion toolkit (adapted from abidjan) for turning an `.Rmd` deck into a
  bilingual `.qmd` later. The converter emits `::: es` / `::: en` shorthand
  with Spanish first; it assumes the source's LEFT column is Spanish, so swap
  columns first when converting from the EN-left `Slides_bilingual_fr_en`
  decks.

## Build and publish

```sh
cd santiago_2026
Rscript 0_make_everything.R --index-only
```

Then commit the changed files (including the regenerated `index.html`) and
push `main`. GitHub Pages serves the repo root directly; there is no CI and
no `docs/` folder. Keep the repo-root `.nojekyll`.

Note: the repo-root `.gitignore` ignores `*.tex`, so `forms/columns.tex` and
`r_sessions/columns.tex` (needed to knit `formato-presentacion.Rmd` and
`TA-rsession1.Rmd`) must be added with `git add -f` the first time.

## Converting a deck to a bilingual .qmd (after the workshop)

1. Start from the deck's `.Rmd` in `slides/` (or the canonical source in
   `../Slides_esp/` / `../Slides/`). `scripts/convert_bilingual_rmd.py`
   scaffolds the qmd; see `../abidjan_2026/ROUTING.md` for the full
   authoring conventions.
2. Authoring convention (mirrored from abidjan, with Spanish primary):
   slide titles `## Titulo en espanol | *English title*`; bodies as paired
   shorthand divs, Spanish first:

   ```markdown
   ::: es
   - Punto en espanol
   :::
   ::: en
   - Point in English
   :::
   ```

   The Lua filter pairs consecutive `::: es` / `::: en` divs into columns,
   uses the Spanish text for slide ids and the menu, and puts the English
   title in `\framesubtitle{}` for beamer. `SANTIAGO_LANG=es|en` renders a
   single-language version (used by future PDF/book exports;
   `R/pdf_lang_helpers.R` exposes `pick_lang(es, en)` for R chunks). In the
   rendered deck, Alt+B / Alt+S / Alt+E toggle both/Spanish/English (bare
   B and S belong to reveal.js: blackout and speaker notes).
3. Save the `.qmd` at the FOLDER ROOT (like abidjan) -- not inside `slides/`;
   the header include paths (`assets/santiago-bilingual.css` etc.) are
   document-relative and only resolve from the root. Run
   `Rscript 0_make_everything.R --html-only`, then set BOTH `href_es` and
   `href_en` for that row in `index.csv` to `<stem>.html`. The badge
   disappears automatically and the format-link row picks up the QMD and any
   `pdf/<stem>.pdf`.
